## Decision

**V3 passes T1, T2 and T3 → V3 replaces V1b as the default WISER track for the implanted animals** (SF07–SF12 wherever the
head-IMU QC passes; where it fails, and in the ± 10-min margins, V3 *is* B2 by construction — same filter, no splice).
**B2 stays the universal baseline** (tags without an IMU, e.g. the five females released 09-11, every IMU-failed stretch).
Nothing was tuned. Four sensitivities would also pass (V3-σ0.5, V3-σ1.0, V3-×30, V3-loco) — a proposal to the user only;
V3-×3 fails T1.

V3 = the pilot's B2 (q = 3 in²/s³, anchors_used noise table, χ² gate + 2 Huber IRLS passes, k_H = 2.5, forward KF + RTS) with
(1) q × 10 on every step whose midpoint second is IMU-QC-ok and locomoting (the pilot's m_loco, unchanged), × 1 elsewhere, and
(2) pseudo-measurements 0 = v_x, 0 = v_y, σ_ZUPT = 0.25 in/s, Huber-weighted inside the IRLS passes, at fixes inside runs of
≥ 3 IMU-QC-ok still seconds eroded by 1 s at each end; no release.

## Definitions (headline quantities; full set in the report)

- **Process noise of V3** $q_k=q\,\mu_k$, $\mu_k=10$ if the second containing $(t_{k-1}+t_k)/2$ has IMU state 3 (QC-ok,
  locomoting), else 1; $q$ = 3 in²/s³. **Text:** more acceleration variance only where the IMU says locomoting.
- **ZUPT** $0=v_{k,a}+\epsilon$, $\epsilon\sim\mathcal N(0,\sigma_Z^2/w^Z_k)$, $\sigma_Z$ = 0.25 in/s, $w^Z_k=\min(1,2.5\,\sigma_Z/\lVert\hat{\mathbf v}_k\rVert)$,
  at fixes in $[s_a+1,s_b-1)$ of every run of $n\ge3$ IMU-QC-ok still seconds. **Text:** velocity told to be zero where the
  head is still; no release.
- **Clean-WISER speed / track speed** $u_3(s)=\lVert\mathbf m_{0.5}(c+1.5)-\mathbf m_{0.5}(c-1.5)\rVert/3$ s, $\mathbf m_h(g)$ = coordinate-wise
  median of the raw fixes in $[g-h,g+h)$, $c=s+0.5$; $v_3$ = the same on the track (in/s). Clean second: ≥ 8 anchors, valid,
  unmasked, no raw jump, ≥ 12 fixes in $[c-2,c+2]$, both medians outside the houses (+14 in), IMU-QC-ok (step B).
- **T1** $d_{95}=Q_{95}(v_3)/Q_{95}(u_3)-1$ on paired clean seconds, all and $u_3>15$ in/s; pass if both $|d_{95}|\le3\%$.
  **Text:** negative = the track under-follows fast motion relative to a smoother-independent reference.
- **T2 jump** $\lVert\hat{\mathbf p}_{k+1}-\hat{\mathbf p}_k\rVert>30$ in with $t_{k+1}-t_k\le0.35$ s; pass if 0 in every primary certified
  still segment and 0 over the analysis masks.
- **T3** $\Delta\lambda=\lambda_{V3}-\lambda_{B2}$ per S5 event ($\lambda^{\text{on}}$ = first 0.25-s grid time with the 1-s centred speed
  ≥ 3 in/s after the still run's end, minus that end; $\lambda^{\text{off}}$ = last such time before the run's start + 0.25 s,
  minus that start); pass if $\operatorname{median}\Delta\lambda\le+0.5$ s per set × kind. **Text:** V3 must not start or stop
  later than B2.
- **NIS** $\sum_a(z_{k,a}-\hat p^-_{k,a})^2/(P^-_{k,aa}+\sigma_a^2(A_k))$, final forward pass, nominal noise; $\chi^2_2$ mean 2 if consistent.
- **Jitter distance** $\delta_k$ = time to the nearest ZUPT fix or end fix of a locomoting step of V3; (i) uses $\delta_k\ge3$ s
  on IMU-active fixes; (ii) clean seconds with IMU state 3 and $u_3<1.64$ in/s (step B's floor p95).

## Caveats

- T1's reference exists only on clean open-field seconds (≥ 8 anchors): speed under poor anchors and in the houses is
  unreferenced; the > 15 band is selected on the noisy reference; × 10, the locomotion class and B2's q were tuned on 09-08/09,
  one of the T1 nights.
- Still metrics are circular; ≥ 95 % of certified stillness is in the houses.
- The × 10 inflates 1-s speed on in-place activity misclassified as locomotion (+62 % p50 vs B2): summed path or activity
  measures will differ between V3 and B2/V1b even where the rat does not translate.
- Speed CIs are quantised in ≈ 0.28 % steps (histogram bootstrap, step B's code).
