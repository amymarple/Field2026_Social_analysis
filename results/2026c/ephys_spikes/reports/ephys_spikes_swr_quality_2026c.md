- **Session filter (the `tier` column):** use `validated` and `good`; look at `check` before use (the reason says why); `low_contrast` = not SWR-specific, a negative control only (SF11 after 09-02 19:08, SF12 block 3); never use `exclude`. Drop events after `use_until` (valid_until / paddock end / SF12 contact failure).
- **Read the `info` column** for regime context that does not change the tier: post-advance settle windows, FM64 sessions, the five females from 09-11 19:40, SF12 shank-1 degradation, sleep review 'bad'.
- **Rates** are per minute of the final 1-s sleep state (`ephys/configs/sleep_final_2026c.yaml`). Compare across animals with care: the detection threshold is each block's own boundary (the user judged ripples by absolute amplitude).

## Definitions

Units: events per minute; fractions in %; times are session seconds (sample / 1250 Hz) unless stated.

### Candidate and selected fraction ($f_{sel}$)
$$ f_{sel} = \frac{\#\{i \in C_{ok} : \lVert z_i - c_{sel} \rVert < \lVert z_i - c_{rest} \rVert\}}{|C_{ok}|} $$
where $C_{ok}$ = the non-artefact DetectSWR candidates (the maximum per 40-ms window of the swDiff / ripPower features), $z_i$ = their features standardised with the block reference's NREM mean and SD, and $c_{sel}, c_{rest}$ = the block reference's 2-cluster k-means centres (minority = selected). **Text:** the share of candidates on the ripple side of the block boundary. Range 0-100 %; validated sessions 2.8-8.2 %; > 10 % = the boundary cuts into the bulk (no ripple cluster). `own_fit_frac` = the same with the session's own NREM fit (a drift diagnostic).

### Event rate ($r_X$, $r^{kept}_X$)
$$ r_X = \frac{\#\{\text{events with the 1-s state } X \text{ at the peak}\}}{\text{minutes of state } X \text{ in the session}} $$
**Text:** events per minute of NREM / REM / WAKE (all events, or `excluded == False`). Validated NREM 36-79/min, the user's own 44-68/min. Check range for all events in NREM: 20-110/min (with >= 10 min NREM).

### NREM amplitude ratio ($A$)
$$ A = \frac{\operatorname{median}_{\text{NREM events of the session}} \text{amplitude}}{\operatorname{median}_{\text{NREM events of the block reference}} \text{amplitude}} $$
**Text:** ripple amplitude relative to the session that set the boundary; it drifts with the probe / contact. Check range 0.7-1.4 (SF09 09-09 night 0.6 = fewer events).

### Event F1 against the user
$$ P = \frac{n_{match}}{n_{auto}},\quad R = \frac{n_{match}}{n_{user}},\quad F1 = \frac{2PR}{P+R} $$
where a match = an automatic and a user event whose trough peaks are within 10 ms (greedy one-to-one on sorted peaks); the user's events = their GUI clicks propagated and localised exactly as DetectSWR's check mode. A block is `validated` when a user-scored session in it has kept-event F1 >= 0.8.

### Flags at the event peak
- `x_rem`: the 1-s state is REM. `x_theta`: theta/delta (+-0.5 s, ripple channel) above the block reference's NREM 95th percentile. `x_moving`: head-IMU EMG proxy above the sleep scorer's own EMG threshold of the session. `x_emg_lfp`: the pipeline's EMGFromLFP (300-450 Hz cross-shank correlation, +-0.5 s) above the block reference's NREM 95th percentile.
